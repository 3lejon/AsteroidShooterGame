Asterod Shooter Game(ASG) is
A quick, arcade‑style space shooter where you blast asteroids, dodge Asteroids, and get high scores.
a game for those looking for a challenge

🎮 How to Play
Move your ship to avoid incoming asteroids

destroy them to get points 

Survive as long as possible with 3 total lives 




🕹️ Controls
Move: WASD / Arrow Keys

Shoot: Space / lmb
